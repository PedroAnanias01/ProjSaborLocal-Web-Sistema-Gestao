# Sabor Local Web - Sistema Gestão

O **Sabor Local Web** é um projeto acadêmico de desenvolvimento de um sistema de gestão criado para complementar o ecossistema Sabor Local. Seu objetivo é centralizar informações operacionais, apoiar a administração do restaurante e facilitar o acompanhamento dos processos envolvidos no serviço de delivery.

O sistema foi desenvolvido com foco em organização, integração e praticidade, oferecendo uma interface administrativa para gerenciamento das operações relacionadas ao aplicativo e aos pedidos realizados pelos clientes.

## Tecnologias utilizadas
- FlutterFlow
- Flutter
- Dart
- Xano
- Figma
- Trello
- Miro

## Objetivo do projeto
Criar uma plataforma de gestão integrada ao ecossistema Sabor Local, permitindo o acompanhamento e a administração das operações do restaurante em uma solução centralizada.

## Status
Projeto acadêmico concluído (1º semestre de graduação).
